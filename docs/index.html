Every friend below is drawn by code from a small JSON spec, in the Little Magic Studio look: hooded chibi bots, coloured pencil on sketchbook paper. Tap a friend to open their spec in the lab and change it.

How the bot will draw

  1. RequestSomeone asks for a friend: a reply, a message or a form.
  2. SpecThe AI fills in the JSON spec from fixed options only. It never draws pixels.
  3. RenderThis renderer turns the spec into a pencil doodle, the same way every time.
  4. SheetThe new friend joins the character sheet with a washi-tape name label.
