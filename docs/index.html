Amra's Doodle Bot ✦

Every friend here is drawn by code from a small JSON spec. Download anyone as a transparent PNG or an SVG, tweak them in the spec lab, or put them in a scene for a thumbnail.

Studio The Luna Crown Scene maker

How the bot draws

  1. RequestSomeone asks for a friend: a reply, a message or a form.
  2. SpecThe AI fills in a JSON spec from fixed options only. It never draws pixels.
  3. RenderThe renderer turns the spec into a pen doodle, the same way every time.
  4. UseDownload the PNG or SVG, or drop the friend into a scene.
